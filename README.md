# Zepix
🧩 Zepix – Smart Dependency Manager
Zepix is a Python-based project that simulates a smart dependency management system.
The project focuses on clean architecture, modular design, and applying core Python concepts in a practical way.

🎯 Project Objective

The goal of Zepix is to:

Read dependency data from files

Clean and validate the input

Resolve dependencies using structured logic

Keep the codebase organized, readable, and easy to extend

This project was built as a learning-focused implementation, emphasizing logic and structure rather than UI.

🚀 Features

Modular and well-organized Python files

Clear separation of responsibilities

Input validation and data cleaning

Dependency resolution logic

Included test files for validation

🗂 Project Structure
Zepix/
│── main.py        # Entry point of the project
│── manager.py    # Manages dependency workflow
│── resolver.py   # Handles dependency resolution logic
│── reader.py     # Reads input files
│── clean.py      # Cleans and validates data
│── logo.py       # Project logo / branding
│── test1.json
│── test6.txt
│── README.md

▶️ How to Run

Make sure Python is installed on your system

Clone the repository

Run the main file:

python main.py

🧪 Testing

Multiple test files are included (.json and .txt) to verify and validate the dependency resolution logic under different scenarios.
